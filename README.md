# SpecSheet

SpecSheet is a full-stack vehicle ownership and build management platform for tracking personal vehicles, maintenance, modifications, expenses, build plans, and ownership analytics.

## Status

V1 development in progress.

Completed so far:

- Django REST Framework backend foundation
- React + TypeScript + Vite frontend foundation
- PostgreSQL database integration
- Docker-based backend and database development environment
- Frontend/backend API integration
- JWT-based user authentication
- User registration and login
- Logout with token invalidation
- Protected frontend routes
- Backend and frontend authentication tests

Currently working on:

- Core authenticated application layout
- Dashboard and navigation structure
